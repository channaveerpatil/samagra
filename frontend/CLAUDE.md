# Enterprise React Starter Kit

This project is a reusable enterprise React foundation built with React, Vite and TypeScript.

The objective is to create a scalable architecture that can be reused across multiple enterprise applications.

The focus is on maintainability, consistency, reusability and clean architecture.

Every implementation should improve the platform rather than solving only the immediate feature request.

## Technology

React

Vite

TypeScript

React Router

Material UI

TanStack Query

React Hook Form

CSS Modules

## TypeScript Rules

Enable strict mode.

Never use any.

Prefer interfaces for public contracts.

Use type aliases for unions.

Avoid unnecessary type assertions.

Export shared types from dedicated files.
